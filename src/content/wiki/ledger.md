## Що це таке

Ledger — це комплексна система аудит-логування для серверів на Fabric. Він тихо відстежує сотні різних подій у світі у фоновому режимі та зберігає їх у базі даних, дозволяючи модераторам(в нашому випадку усім гравцям) перевіряти, що відбувалось у будь-якому місці, та відкочувати пошкодження у разі необхідності.

---

## Що логується

Ledger відстежує величезний перелік подій:

**Події блоків**
- Розміщення блоку (гравцем, поршнем, ендерменом, падіючим піском тощо)
- Зламування блоку (гравцем, вибухом, вогнем, ізердом тощо)
- Зміна блоку (рілля витоптана, табличка відредагована, нотний блок налаштований тощо)

**Події контейнерів**
- Предмети покладені до скринь, барелів, печей, скидників тощо
- Предмети забрані з контейнерів
- Предмети, кинуті на землю
- Предмети, підібрані гравцями

**Події сутностей**
- Вбиті сутності (гравцем, мобом, оточенням)
- Спавн і деспавн мобів

**Природні події**
- Поширення вогню
- Срібна рибка заражає камінь
- Зростання та знищення врожаю
- Взаємодія лави та води

Кожен запис у логах містить: **хто**, **що**, **де** (вимір + координати), **коли** та **тип дії**.

## Режим інспекції

Найпоширеніший спосіб використання Ledger — **інструмент інспекції**. При увімкненні — клік по будь-якому блоку показує його повну історію в чаті: кожного разу, коли він був розміщений, зламаний або змінений, ким і коли.

Щоб увімкнути режим інспекції:
```
/lg inspect
```
або скорочено:
```
/lg i
```

Клікни по будь-якому блоку в режимі інспекції, щоб побачити його історію. Запусти команду ще раз, щоб вимкнути. Також можна перевірити конкретну позицію без кліку:
```
/lg inspect <x> <y> <z>
```

## Команди

Усі команди використовують `/ledger` або псевдонім `/lg`.

### Інспекція та пошук

| Команда | Опис |
|---|---|
| `/lg inspect` | Вмикає/вимикає режим інспекції |
| `/lg inspect on` / `/lg inspect off` | Явно вмикає або вимикає режим інспекції |
| `/lg inspect <x y z>` | Інспектує конкретну позицію блоку |
| `/lg search <параметри>` | Шукає в базі даних за фільтрами |

**Параметри фільтрів пошуку** (можна комбінувати будь-яку кількість):

| Параметр | Приклад | Опис |
|---|---|---|
| `source:<гравець>` | `source:Степан` | Фільтр за тим, хто спричинив дію |
| `object:<блок>` | `object:minecraft:chest` | Фільтр за блоком або предметом |
| `action:<тип>` | `action:block-place` | Фільтр за типом дії |
| `world:<вимір>` | `world:overworld` | Фільтр за виміром |
| `before:<час>` | `before:2h` | Лише записи давніші за X часу |
| `after:<час>` | `after:1d` | Лише записи новіші за X часу |
| `rolledback:<bool>` | `rolledback:false` | Лише записи без відкату |
| `page:<номер>` | `page:2` | Навігація по сторінках результатів |

Будь-який фільтр можна заперечити через `!`: `source:!Степан` (все, крім Степана).

**Типи дій** для фільтру `action:`:
- `block-break`, `block-place`, `block-change`
- `item-remove`, `item-insert`, `item-drop`, `item-pickup`
- `entity-kill`

**Формат часу:** `30s` = 30 секунд, `2h` = 2 години, `1d` = 1 день, `1w` = 1 тиждень

**Приклади пошуку:**
```
/lg search source:Степан action:block-break after:1h
/lg search object:minecraft:diamond_block world:overworld
/lg search source:Степан action:item-remove after:6h
```

## Читання результатів

Результати пошуку та інспекції з'являються в чаті з кольоровими записами. Кожен запис показує:

```
[час] [дія] [об'єкт] на (x, y, z) від [гравець/джерело]
```

Записи з відкатом відображаються з закресленням.

Клік по результату в чаті часто автоматично заповнює команду `/lg tp` для телепортації прямо до цього місця.
