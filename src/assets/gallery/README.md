# Папка галереї

Помісти сюди скріншоти у форматі `.jpg`, `.jpeg`, `.png`, `.webp` або `.gif`.

## Як це працює зараз

- Зображення з цієї папки автоматично з'являються на сторінці `/gallery/`.
- Підпис і дата беруться не з компонента, а з файлу `src/data/gallery.metadata.json`.
- Ключ у JSON має точно збігатися з назвою файлу зображення.

## Що редагувати

1. Додай картинку в цю папку.
2. Додай для неї запис у `src/data/gallery.metadata.json`.
3. Вкажи `title` і `date`.

## Fallback-поведінка

Якщо метадані для файлу не знайдені, сайт автоматично згенерує назву з імені файлу.
