# 🌲 1. Айдентика Pinecraft

## 🔹 Концепція

**"Живий світ + спільнота + геополітика"**

Твоє ядро (з файлу):

* міста / нації / клани
* дипломатія
* ваніль + соціум
* карта в реальному часі

👉 Це не просто Minecraft сервер → це **симуляція світу**

---

## 🎨 Візуальний стиль

### Основна ідея

* Minecraft, але НЕ кричущий
* більш "натуральний / атмосферний"
* легкий RPG / geopolitical feel

---

## 🌈 Кольори

```css
--bg: #0f1720;            /* темний нічний */
--primary: #4ade80;       /* зелений (природа) */
--secondary: #22c55e;     /* акцент */
--accent: #a3e635;        /* лаймовий */
--text: #e5e7eb;          /* світлий текст */
--muted: #64748b;         /* другорядний */
--danger: #ef4444;        /* PvP / правила */
```

👉 Альтернатива:
додати **earth tones** (коричневий, пісок) для "ванільності"

---

## 🔤 Типографіка

* Headings: `Inter / Sora / Space Grotesk`
* UI: `Inter`
* Акценти (опціонально): Minecraft-style pixel font (тільки для декору)

---

## 🧱 UI стиль

* rounded-xl / 2xl
* легкі glass / blur блоки
* subtle borders (`1px rgba(255,255,255,0.08)`)
