# Туторіал: як наповнювати сайт Pinecraft

Цей гайд показує, як додавати новини, події, сторінки вікі та зображення галереї.

## 1. Запуск локального середовища

```bash
npm ci --legacy-peer-deps
npm run dev
```

Відкрий локальний сайт за адресою, яку покаже Astro (зазвичай `http://localhost:4321` або `http://localhost:4322`).

## 2. Додавання новини

1. Створи новий файл у папці `src/content/post/`, наприклад `summer-update.md`.
2. Заповни frontmatter і текст статті.

Приклад:

```md
---
title: "Літнє оновлення"
description: "Що нового на сервері цього місяця"
publishDate: 2026-04-13
tags: ["update", "server"]
---

Тут текст новини у Markdown.
```

Новина автоматично зʼявиться:
- у стрічці `/news/`
- на сторінці конкретного поста `/news/<slug>/`
- в блоці останніх новин на головній

## 3. Додавання події

1. Створи файл у `src/content/event/`, наприклад `spring-war.md`.
2. Заповни frontmatter.

Приклад:

```md
---
title: "Весняна Війна"
description: "Сезонне PvP-змагання націй"
date: "20 квітня 2026"
status: "upcoming"
badge: "PvP"
---

Опис події.
```

`status` може бути:
- `upcoming`
- `active`
- `ended`

Події показуються на сторінці `/events/` і на головній.

## 4. Додавання сторінки Wiki

1. Створи файл у `src/content/wiki/`, наприклад `economy.md`.
2. Додай frontmatter:

```md
---
title: "Економіка"
description: "Як працює торгівля і ринки"
icon: "💰"
badge: "Guide"
badgeColor: "#4ade80"
order: 5
---

Контент сторінки у Markdown.
```

Сторінка буде доступна за адресою `/wiki/economy/`.

## 5. Додавання зображень у галерею

1. Додай файли у `src/assets/gallery/`.
2. Підтримувані формати: `jpg`, `jpeg`, `png`, `webp`, `gif`.

Зображення автоматично:
- зʼявляються на сторінці `/gallery/`
- підтягуються в галерейний блок на головній

Підпис генерується з назви файлу. Наприклад:
`my-city-night.png` -> `My City Night`.

## 6. Логотипи та брендинг

Логотипи сайту зберігаються в `public/brand/`:
- `LogoSquare.svg`
- `PINECRAFT-banner.svg`

Використання в шаблонах:

```astro
<img src="/brand/LogoSquare.svg" alt="Pinecraft" />
```

## 7. Оновлення навігації

Пункти меню редагуються в `src/site.config.ts` (масив `menuLinks`).

Після зміни меню оновиться у хедерах і футерах.

## 8. Перевірка перед публікацією

```bash
npm run build
```

Якщо збірка проходить без помилок, контент готовий до деплою.

## 9. Рекомендації по контенту

- Усі заголовки роби короткими і читабельними.
- В `description` пиши 1-2 речення для превʼю-карток.
- Уникай дуже довгих slug-ів у назвах файлів.
- Для галереї краще використовувати зображення зі співвідношенням близько 16:9.
