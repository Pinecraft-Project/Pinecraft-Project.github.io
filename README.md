# Pinecraft Website

Офіційний сайт сервера Pinecraft на Astro.

## Стек

- Astro
- TypeScript
- Tailwind CSS
- Astro Content Collections

## Локальний запуск

```bash
npm ci --legacy-peer-deps
npm run dev
```

## Продакшн-збірка

```bash
npm run build
```

## Основні розділи контенту

- Новини: `src/content/post/`
- Події: `src/content/event/`
- Wiki: `src/content/wiki/`
- Галерея: `src/assets/gallery/`
- Логотипи: `public/brand/`
