Pinecraft використовує **GeyserMC** — міст між Java та Bedrock. Жодних модів встановлювати не потрібно.

## Кроки підключення

### 1. Відкрий Minecraft (Bedrock)
Запусти гру на своєму пристрої. Перейди до меню **«Грати»**, потім обери вкладку **«Сервери»**.

### 2. Додай зовнішній сервер
Прокрути список серверів донизу та натисни **«Додати сервер»**.

### 3. Введи дані сервера

| Поле | Значення |
|---|---|
| Назва сервера | Pinecraft |
| Адреса сервера | `pinecraft.top` |
| Порт | `19132` |

### 4. Підключись і грай
Збережи сервер і натисни **«Підключитись»**. Ти потрапиш у вітальне лобі, де можна переглянути правила та обрати стартовий регіон.

> **Для Java Edition**: підключайся на `pinecraft.top`, порт за замовчуванням `25565`.

## Відомі проблеми Bedrock

- **Скіни** — Bedrock скіни повністю підтримуються через Floodgate.
- **Команди** — деякі команди Java Edition можуть не працювати; перевір список у Discord.
- **Лагаючий рендер** — знизь дальність промальовки до 8 чанків для стабільнішої роботи.
