Політична система — серце Pinecraft. Від самотнього поселення до континентальної імперії.

## Міста

Місто — базова політична одиниця. Будь-який гравець з достатньою кількістю ресурсів може заснувати місто:

```
/city new <назва>
```

Міста клеймують сусідні чанки. Заклеймована земля захищена — будувати там можуть лише члени міста. Мер встановлює дозволи для гостей, союзників та ворогів.

Міста ростуть, залучаючи мешканців. Більше мешканців = більший радіус клейму та доступ до розширень.

### Корисні команди

| Команда | Опис |
|---|---|
| `/city new <назва>` | Заснувати місто |
| `/city claim` | Заклеймувати поточний чанк |
| `/city invite <гравець>` | Запросити мешканця |
| `/city info` | Переглянути статистику міста |
| `/city leave` | Покинути місто |

## Нації

Нації — це союзи міст під спільним урядом. Для нації потрібне столичне місто з мінімум 5 мешканцями.

Нації відкривають: спільні бойові бонуси, дипломатію, торговельні угоди та можливість оголошувати війни іншим націям.

| Команда | Опис |
|---|---|
| `/nation new <назва>` | Заснувати націю (потрібне столичне місто) |
| `/nation add <місто>` | Запросити місто до нації |
| `/nation ally <нація>` | Запропонувати союз |
| `/nation declare war <нація>` | Оголосити війну |

## Дипломатія

Нації можуть формувати союзи, підписувати пакти ненападу або оголошувати війни. Дипломатія відбувається між гравцями — через голосовий чат або Discord.

Війни мають:
1. **Фазу оголошення** — 24 год попередження
2. **Активну бойову фазу** — відкрите PvP у зонах конфлікту
3. **Фазу мирного договору** — гравці домовляються про умови; можлива передача земель
